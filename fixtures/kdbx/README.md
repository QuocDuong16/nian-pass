# KDBX fixtures

Never place a real vault in this directory. Every committed database must use
synthetic, public test data only; production credentials, personal data, and
private key files are forbidden. Test master passwords may be public.

All fixtures below were copied byte-for-byte from the `keepass-rs` upstream
test resources at commit `2f1dd5e0f1a23dc7420c3fa25f434fe362729b24`.
Their checked-in hashes were verified after copying. `Creator` comes from the
decrypted KDBX `Meta/Generator` field or an upstream source statement; an
unknown creator version is recorded as unknown rather than inferred.

These fixtures are used only for read compatibility tests. None was generated
by Nian Pass, and none is evidence of lossless writing, round-trip
preservation, or complete feature support for its KDBX version. Future fixtures
must come from a released external KeePass implementation or a trustworthy
upstream test suite and record creator, version when known, format, public test
credential, KDF, cipher, features, provenance, upstream commit, and checksum.
