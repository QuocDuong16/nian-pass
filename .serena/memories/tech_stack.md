# Tech stack

- Rust 2024 workspace: reusable domain/persistence/sync crates plus Tauri desktop, CLI, Native Messaging host, and Linux sync gateway.
- Desktop: Tauri 2 with React/TypeScript, Vite, pnpm; Node scripts enforce architecture, security, release, and documentation policy. Both frontends alias `typescript` to `@typescript/typescript6` so typescript-eslint and Knip keep the TypeScript 6 JS API, while `@typescript/native` aliases TypeScript 7 and supplies the `tsc` binary used by `typecheck`; keep both aliases pinned until typescript-eslint supports TS 7.
- Mobile host code includes generated Tauri Android/Kotlin integration and retained iOS/Swift FFI foundations.
- Forgejo is the canonical quality CI; GitHub workflows cover release and Windows diagnostics. Docker builds the self-hosted gateway.
- `mise.toml` is the toolchain source of truth; `mise.lock` locks tool metadata. Rustup, Cargo MSRV, `.node-version`, package engines, containers, and CI values are checked mirrors. The sync-gateway Rust builder image must match the `rust-toolchain.toml` channel and use a SHA-256 digest.
- Bumping the mise Rust pin provisions a fresh rustup toolchain that does not necessarily carry the `components` and `targets` declared in `rust-toolchain.toml`; a rustup sync can be triggered later by tool installs and fail partway, and does not run at all for plain `cargo` calls in a mise-activated shell (mise pins `RUSTUP_TOOLCHAIN`). After any Rust bump run `make toolchain-install` and confirm with `make tools-check`, which asserts `llvm-tools`, not just the versions.
- Every Rust quality tool is mise-pinned: `cargo-audit`, `cargo-deny`, `cargo-machete`, and `cargo-llvm-cov` live in `mise.toml` with `mise.lock` entries, and `make toolchain-install` installs them all. `cargo-outdated` is intentionally not pinned: 0.19 silently ignores `[workspace.dependencies]` inheritance, so `make rust-outdated` runs `scripts/run_cargo_outdated.mjs`, which reads `cargo metadata --no-deps` and the crates.io sparse index instead. Gates call `cargo deny`, `cargo machete`, and `cargo llvm-cov` resolved from PATH (mise shims on developer machines, cargo's bin directory in CI), `make tools-check` verifies both the mise pins and the resolved binaries, and CI containers — which have no mise — install the same pinned versions with `make tools-install-ci`. Stray global copies earlier on PATH shadow the mise-managed tools, so stale copies such as a `~/.cargo/bin` install must be removed.
- Serena project servers: TypeScript, Rust, and Bash, indexed from the repository root.
